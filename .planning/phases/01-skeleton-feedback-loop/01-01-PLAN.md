**nothing in the build pipeline could tell** — `build` compiled it, `runData` never
touched the client, and the only test loop was hand-copying a jar. This plan builds the
feedback loop that makes that class of bug a 20-second discovery.

Output: a buildable, launchable skeleton jar (`secondshift-0.1.0.jar`) plus the
registration guardrail, the client/server package split, and the `pack.mcmeta` /
singular-data-folder convention (POL-09).
