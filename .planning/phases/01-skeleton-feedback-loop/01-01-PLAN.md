<objective>
Bootstrap the pinned NeoForge 1.21.1 / ModDevGradle 2.0.146 project from the official MDK,
stand up the `@Mod` entrypoint, add the first **real** `DeferredRegister<Item>` (one
throwaway debug entry — D-07), and wire the `FMLLoadCompleteEvent` unbound-registry
self-check (D-08/D-09/D-10). Prove the whole thing with `./gradlew build`,
`./gradlew runClient`, `./gradlew runServer`, and a deliberate detach-a-register abort test
run under **both** `runData` and `runClient`.

Purpose: the prior draft shipped a `MenuType` that was never added to a registry and
**nothing in the build pipeline could tell** — `build` compiled it, `runData` never
touched the client, and the only test loop was hand-copying a jar. This plan builds the
feedback loop that makes that class of bug a 20-second discovery.

Output: a buildable, launchable skeleton jar (`secondshift-0.1.0.jar`) plus the
registration guardrail, the client/server package split, and the `pack.mcmeta` /
singular-data-folder convention (POL-09).
</objective>
