<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Gradle build → `test_instance_mods_dir` (a filesystem path **outside** the repo, from committed `gradle.properties`) | `deployToTest` deletes and writes files under a user-controlled absolute path |
| committed `gradle.properties` | carries a machine-specific absolute path (D-06) |
| Gradle build ← plugins / dependencies | inherited from plan 01-01; nothing new added here |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-01-06 | Tampering | `deployToTest` glob-delete could remove files other than the intended jar | mitigate | The delete filter is exactly `secondshift-*.jar` — never a bare `*.jar`, never recursive, never the dashed `second-shift-*.jar` (D-05). Copy-only; the `build/libs` jar is never moved or deleted (D-02 / D-04). |
| T-01-07 | Elevation / path abuse | a malicious `test_instance_mods_dir` value could aim `deployToTest` at a system directory | accept | The value is committed personal-machine config edited only by the developer (D-06); single-user machine; the task refuses to run when the path does not already exist (so it cannot create arbitrary trees). |
| T-01-08 | Denial of service | `deployToTest` run while Minecraft holds a Windows lock on the jar | mitigate | Caught and rethrown as an actionable `GradleException` ("close Minecraft and re-run"); never warn-and-continue (D-04); `build/libs/secondshift-0.1.0.jar` always remains, so a failed deploy can never leave a silent stale jar in the instance. |
| T-01-09 | Information disclosure | the committed absolute path exposes the local Windows username | accept | Personal repo, no public release (PROJECT.md "Distribution: personal use only"); the path is already implied by PROJECT.md's build-ownership constraint. |
| T-01-SC | Tampering (supply chain, tracked) | no new package / plugin / archive installs in this plan | accept | Inherits plan 01-01's pinned toolchain; nothing is added or downloaded here. |
</threat_model>
