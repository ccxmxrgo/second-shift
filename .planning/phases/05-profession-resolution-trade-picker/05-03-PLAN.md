    `private static final float HOVER_SCALE = 0.4F;`, `private static final float

    not touch that block's code, do not early-return before it), add: if `!be.isJobItemEmpty() &&
    be.getHeldJobItem().getItem() instanceof BlockItem blockItem`, resolve
    `BlockState jobState = blockItem.getBlock().defaultBlockState()`, compute `long gameTime =
    be.getLevel() != null ? be.getLevel().getGameTime() : 0L;` and `float angle = (gameTime +
    partialTick) * SPIN_DEG_PER_TICK;`. In its own `pose.pushPose()`/`pose.popPose()` pair
    (independent of the embedded block's transform stack — never nested inside it, never sharing
    variables across the two blocks): `pose.translate(CENTRE, HOVER_Y, CENTRE);
    pose.mulPose(Axis.YP.rotationDegrees(angle)); pose.scale(HOVER_SCALE, HOVER_SCALE, HOVER_SCALE);
    pose.translate(-0.5D, -0.5D, -0.5D);` then
    `blockRenderer.renderSingleBlock(jobState, pose, buffers, packedLight,
    OverlayTexture.NO_OVERLAY);` — use the render method's own `packedLight` parameter here (NOT
    `LightTexture.FULL_BRIGHT`), since the job item is a normal held block, not an emissive
    artifact (deliberate visual distinction from the embedded Soul Block per UI-SPEC). Import
    `com.mojang.math.Axis` and `net.minecraft.world.item.BlockItem` (already available in
    1.21.1, no new dependency).
